## 总原则（响应"不要打得多数据就好"）

1. **散点轴只允许比率或每回合值**。绝对值（总击杀/总发枪价值/残局总数…）只出现在悬停详情与部分榜单，不上轴。
2. **样本门槛**：出场 ≥3 局才进图（用户指定），门槛可调 2/3/5。
3. **点大小 = 出场数**（样本量=可信度，非好坏），页面注明。
4. 榜单取最大值为王（搞怪榜，最高=王）。

## A. 经济系：发枪与吸血（用户点名，双口径）

### 数据基础：发枪检测链（已实证，全库 314 次成功发枪）

无"掉落"事件，用购买→拾取链条反推。判定四道闸门，缺一不算：

1. 队友 A 在回合 r 购买了主武器 w（`item_purchase.cost` = 价值）；
2. 同回合内队友 B（B≠A，与 A 同阵营）在 T2 拾取了同款 w（`item_pickup`）；
3. B 自己没有在 T2 ±2s 内购买同款 w（排除"自己买枪的自动拾取事件"——已实证买枪必触发 pickup）；
4. A 在 T2 时刻存活（`player_death` 无 A 在 [T1,T2] 的记录——排除死亡掉枪被捡）且 T2−T1 ≤ 30s（买枪时间窗）。

四条全过 → 记一次"发枪 A→B(w, cost)"。武器名归一：大小写统一 + 5E 皮肤前缀剥离（`5e_plusredkill_ak47`→`ak47`）+ 别名表（AK-47→ak47 等）。

**已知残余误差**：B 捡到的是敌人掉的同款枪、且恰有队友买了同款——概率低，30s 窗口进一步压低；不追求审计级精确，搞怪指标可接受。

### A1 发枪贡献（绝对值口径）【新】
- 公式：`Σ 发枪价值`（成功被捡起的）
- 含义：谁在养队。**只进榜单+tooltip，不上轴**（绝对值原则让位，但用户明确要这个绝对值口径——做成"发枪金主"榜单）。

### A2 发枪慷慨率（比例口径）【新】
- 公式：`发枪价值 / 自己总购买花费`
- 含义：我花出去的钱里，多大比例是替队友花的。0.1 = 十分之一的钱在发枪。

### A3 雪中送炭（意愿口径）【新】
- 公式：`己方回合买枪分类 ∈ {eco, force} 时的发枪次数`（榜单）；或 `/ 发枪总次数`（自己穷时发枪占比）
- 含义：自己都没钱还愿不愿意发枪。**用户点名**。

### A4 发枪成材率【新·定稿做】
- 公式：被发枪者当回合**用该武器拿到 ≥1 杀**的发枪 / 总发枪（武器级归属，准确测"这把枪有没有白给"）
- 含义：发出去的枪有没有打水漂。

### B1 被发枪价值（绝对值口径）【新】
- 公式：`Σ 收到的发枪价值`。同 A1，只进榜单（"吸血鬼"榜）+tooltip。

### B2 吸血率（比例口径）【新】
- 公式：`被发枪价值 / (自己购买总花费 + 被发枪价值)`
- 含义：我的装备来源里，队友供枪占比。0.4 = 四成装备是队友喂的。

### B3 浪费发枪【新·定稿做】
- 公式：被发枪后同回合死亡、且死亡前用该武器 0 击杀 → 次数 / 被发枪次数
- 含义：发出去的枪打水漂的比例。

### B5 白嫖枪【新·定稿做】
- 公式（v5 双口径）：
  - **白嫖占比**（散点轴）：`白嫖次数 ÷ (被发枪次数 + 白嫖次数)` —— 收枪来源里捡包占比
  - **白嫖频率**（舔包王榜排序）：`白嫖次数 ÷ 总回合数` —— 用户裁决"除总回合数"
- 判定：拾取主武器且自己该回合未购买该武器，且同款为**阵亡队友**所购（死亡窗口判定）；
  地上敌人的枪是正常战利品，不计。
- 含义：不花钱全靠捡（"舔包王"）。

## B. 击杀风格系

### C1 eco特率【已实现，保留·合并一档】
- 公式：`对手回合买枪 ∈ {eco} 的击杀 / 总击杀`
- 裁决：用户未要求拆分，保持合并（对 force 杀不算 eco特，只对 eco 杀算——低含金量口径）。

### C2 神仙率【已实现，分母定稿】
- 定稿口径：`己方 eco 回合击杀 / 己方 eco 回合数`（每局 eco 平均产出——机会口径，避免"eco 局多的选手天然数值大"）。

### C3 白给率【已实现，门槛定稿】
- 公式：`伤害 <10 的命 / 总命`（**用户裁决：0 伤害太苛刻，10 以下都算白给**）
- 边界：dmg_health 累计（血包/护甲不算）。

### C4 抢人头率【原"收割率"，用户改名·需改归因】
- 现口径缺陷：只看终击时 HP≤30，**自己打残自己收也算了**；要修。
- 新口径：`终击时受害者 HP≤30 且 ≥1 名 队友（≠终结者，同阵营）在该受害者本条命内造成过伤害 → 该击杀为抢人头`
- 公式：`抢人头击杀 / 总击杀`。
- 数据来源：player_death.user_health（受击前 HP，已实证）+ player_hurt 伤害归因。

### C5 被抢人头率【新】（与 C4 配对，用户改名）
- 口径：你把敌人打到 HP≤30 后，**队友（≠你）**终结了该敌人 → 记一次"被抢人头"
- 公式：`被抢人头次数 / (击杀 + 被抢人头次数)`——你参与终结的敌人里，人头被队友拿走的比例。
- 数据来源：player_hurt 时间线 + 击杀事件配对（同一条命内）。

### C6 残局频率【已实现，需改分母】
- 现口径：残局击杀绝对数（**违反总原则，要改**）
- 新口径：`last-alive 状态击杀 / 回合数`
- last-alive 判定：击杀瞬间己方本回合已死亡人数 = 己方人数−1。

### C7 多杀率【新·定稿做】
- 公式：`击杀≥2 的回合数 / 出场回合数`。

## D. 枪械技术（实验区）

### D1 狙击依赖度【新】
- 公式：`AWP 击杀（含 5E 皮肤名变体，base name 归一） / 总击杀`

### D2 急停率【v2 后置】
- 公式：击杀瞬间速度 <60 u/s 且 0.25s 前速度 >150 u/s 的枪杀 / 枪杀数
- **组合视角（用户点名）**：急停率 × 平均 peek 速度（对枪时移动速度）双轴——rdy.gg/LuzRaposa 的
  "Counter Strafing % vs Peek Speed" 范式（reddit r/GlobalOffensive 1vl0d3q）：急停好但 peek 慢=稳健老人，
  peek 快且急停好=donk。peek 速度 = 击杀前 0.25s~0.5s 窗口的平均速度（只统计交战中的移动）。
- 速度来源：ticks.parquet 该玩家 X/Y 位移差分。
